# Skriuw packages

Homebrew cask for [Skriuw](https://skriuw.com), the local-first workspace for notes, journaling, and connected knowledge. Source and releases live in [remcostoeten/skriuw](https://github.com/remcostoeten/skriuw).

```sh
brew install --cask skriuw/tap/skriuw
```

Windows users install from the [skriuw/scoop-bucket](https://github.com/skriuw/scoop-bucket) Scoop bucket. Linux packages (apt, dnf, AUR, Snap) and direct downloads are listed on [skriuw.com/download](https://skriuw.com/download/).

The cask is updated automatically when a v2 release is published. Do not edit `version` or the hashes by hand.
